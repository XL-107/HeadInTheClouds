# Head In the Clouds

As the internet takes more and more of our time, we become less and less productive. 
In this age of ever-increasing distraction, we need a way to bring ourselves back down to Earth when we find our Head in the Clouds.

How To Use:
Download all the files and put them in a file folder (not a .zip, just a folder).
Go to extension manager in Chrome, enable developer mode, and press "load unpacked".
Select the folder and enable the extension.
With that, you're ready to use the extension and elevate your focus!
